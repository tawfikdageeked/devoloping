╔══════════════════════════════════════════════════════════════╗
║                    VIM — THE FULL GUIDE                      ║
║          Everything you need. Nothing you don't.             ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  Vim has MODES. You're always in one of them.                ║
║                                                              ║
║  NORMAL MODE     where you move, delete, copy, command       ║
║  INSERT MODE     where you type text                         ║
║  VISUAL MODE     where you select text                       ║
║  COMMAND MODE    where you type : commands at the bottom     ║
║                                                              ║
║  You start in NORMAL mode. Always.                           ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  ── ENTERING INSERT MODE (from normal) ──────────────────    ║
║                                                              ║
║  i         insert before cursor                              ║
║  a         insert after cursor                               ║
║  I         insert at start of line                           ║
║  A         insert at end of line                             ║
║  o         new line below + insert                           ║
║  O         new line above + insert                           ║
║  s         delete char + insert                              ║
║  S         delete line + insert                              ║
║                                                              ║
║  ── EXITING INSERT MODE ─────────────────────────────────    ║
║                                                              ║
║  Esc       back to normal mode                               ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  ── MOVEMENT (normal mode) ──────────────────────────────    ║
║                                                              ║
║  BASIC:                                                      ║
║  h         left                                              ║
║  j         down                                              ║
║  k         up                                                ║
║  l         right                                             ║
║                                                              ║
║  BY WORD:                                                    ║
║  w         jump to start of next word                        ║
║  b         jump to start of previous word                    ║
║  e         jump to end of current word                       ║
║  W         jump to next WORD (ignores punctuation)           ║
║  B         jump to previous WORD                             ║
║  E         jump to end of WORD                               ║
║                                                              ║
║  BY LINE:                                                    ║
║  0         go to column 0 (very start)                       ║
║  ^         go to first non-space character                   ║
║  $         go to end of line                                 ║
║  g_        go to last non-space character                    ║
║                                                              ║
║  BY SCREEN:                                                  ║
║  H         go to top of screen                               ║
║  M         go to middle of screen                            ║
║  L         go to bottom of screen                            ║
║                                                              ║
║  BY FILE:                                                    ║
║  gg        go to first line of file                          ║
║  G         go to last line of file                           ║
║  42G       go to line 42                                     ║
║  :42       go to line 42                                     ║
║                                                              ║
║  SCROLLING:                                                  ║
║  Ctrl+d    scroll half page down                             ║
║  Ctrl+u    scroll half page up                               ║
║  Ctrl+f    scroll full page down                             ║
║  Ctrl+b    scroll full page up                               ║
║  zz        center screen on cursor                           ║
║  zt        scroll cursor to top                              ║
║  zb        scroll cursor to bottom                           ║
║                                                              ║
║  JUMPING:                                                    ║
║  %         jump to matching bracket () {} []                 ║
║  {         jump to previous empty line                       ║
║  }         jump to next empty line                           ║
║  Ctrl+o    jump back (previous position)                     ║
║  Ctrl+i    jump forward                                      ║
║                                                              ║
║  FIND ON LINE:                                               ║
║  f<char>   jump to next <char> on this line                  ║
║  F<char>   jump to previous <char> on this line              ║
║  t<char>   jump to before next <char>                        ║
║  T<char>   jump to after previous <char>                     ║
║  ;         repeat last f/F/t/T                               ║
║  ,         repeat last f/F/t/T backwards                     ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  ── THE VIM LANGUAGE ────────────────────────────────────    ║
║                                                              ║
║  This is why vim is powerful. Commands follow a grammar:     ║
║                                                              ║
║       [count] [verb] [noun]                                  ║
║                                                              ║
║  VERBS (what to do):                                         ║
║  d         delete                                            ║
║  c         change (delete + enter insert mode)               ║
║  y         yank (copy)                                       ║
║  v         select (visual)                                   ║
║  >         indent right                                      ║
║  <         indent left                                       ║
║  =         auto-indent                                       ║
║  g~        toggle case                                       ║
║  gu        lowercase                                         ║
║  gU        uppercase                                         ║
║                                                              ║
║  NOUNS (what to act on):                                     ║
║  w         word                                              ║
║  b         back word                                         ║
║  e         end of word                                       ║
║  $         end of line                                       ║
║  0         start of line                                     ║
║  ^         first non-space                                   ║
║  G         end of file                                       ║
║  gg        start of file                                     ║
║  j         line below                                        ║
║  k         line above                                        ║
║  %         matching bracket                                  ║
║  iw        inner word                                        ║
║  aw        a word (includes space)                           ║
║  i"        inside quotes                                     ║
║  a"        around quotes (includes quotes)                   ║
║  i(        inside parentheses                                ║
║  a(        around parentheses                                ║
║  i{        inside curly braces                               ║
║  a{        around curly braces                               ║
║  i[        inside square brackets                            ║
║  it        inside HTML tag                                   ║
║  ip        inner paragraph                                   ║
║                                                              ║
║  EXAMPLES:                                                   ║
║  dw        delete word                                       ║
║  d$        delete to end of line                             ║
║  d0        delete to start of line                           ║
║  dG        delete to end of file                             ║
║  dgg       delete to start of file                           ║
║  di"       delete inside quotes                              ║
║  di(       delete inside parentheses                         ║
║  di{       delete inside curly braces                        ║
║  da{       delete around curly braces (including them)       ║
║  diw       delete inner word                                 ║
║  cw        change word (delete + insert mode)                ║
║  ci"       change inside quotes                              ║
║  ci(       change inside parentheses                         ║
║  ciw       change inner word                                 ║
║  yy        copy entire line                                  ║
║  yw        copy word                                         ║
║  yi"       copy inside quotes                                ║
║  yi{       copy inside curly braces                          ║
║  >ip       indent paragraph                                  ║
║  =G        auto-indent entire file (from cursor)             ║
║  gUiw      uppercase inner word                              ║
║  3dw       delete 3 words                                    ║
║  5j        move 5 lines down                                 ║
║  2dd       delete 2 lines                                    ║
║  4yy       copy 4 lines                                      ║
║                                                              ║
║  DOUBLE THE VERB = ACT ON LINE:                              ║
║  dd        delete line                                       ║
║  cc        change line (delete + insert)                     ║
║  yy        yank (copy) line                                  ║
║  >>        indent line right                                 ║
║  <<        indent line left                                  ║
║  ==        auto-indent line                                  ║
║                                                              ║
╠══════════════════════════════════════════════════════════════╣
║                                                              ║
║  ── DELETING ────────────────────────────────────────────    ║
║                                                              ║
║  x         delete character under cursor                     ║
║  X         delete character before cursor (backspace)        ║
║  dd        delete entire line                                ║
║  D         delete from cursor to end of line                 ║
║  dw        delete word                                       ║
║  diw       delete inner word (no space)                      ║
║  daw       delete a word (with space)                        ║
║  di"       delete inside quotes                              ║
║  di(       delete inside parentheses                         ║

║  NOTE: everything deleted goes into a register               ║
║        (clipboard) so you can paste it with p                ║

║                                                              ║
║  ── THE GOLDEN RULES ────────────────────────────────────    ║
║                                                              ║
║  1. Stay in NORMAL mode. Only enter INSERT to type.          ║
║  2. Never use arrow keys. Use h j k l.                       ║
║  3. Never hold down a key. Use counts (5j = 5 down).         ║
║  4. Use the DOT command (.) to repeat.                       ║
║  5. Use text objects (ciw, di", yi{).                        ║
║  6. If you're doing it more than twice, record a macro.      ║
║  7. Learn one new thing per week. Don't rush.                ║
